Model API Lab U盘精简版
=======================

使用方法
1. 将整个“Model-API-Lab-U盘精简版”文件夹复制到U盘。
2. 在64位 Windows 10或Windows 11电脑上双击“打开模型API课堂.cmd”。
3. 网页会自动打开，不需要安装Node.js，也不需要手动输入端口。
4. 在网页左侧填写Base URL、模型名和API Key，然后点击“应用配置”。

说明
- 本版本只包含编译后的网页和运行环境，容量较小，适合课堂分发。
- 本版本不能直接修改源代码；需要修改功能时，请使用原来的完整版项目。
- 调用云端大模型时仍然需要联网。
- API Key只保留在当前网页内存中，不会写入这个文件夹。
- 请保持dist、runtime、scripts和server.mjs完整，不要只复制启动文件。
